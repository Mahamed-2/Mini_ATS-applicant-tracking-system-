## Scene Narration Details

### Scene 1 – Architecture & Introduction (0:00–0:30)

Show `docs/demo/images/01-architecture.svg` or live browser.

**Narration:**
> *"Welcome to the Mini ATS prototype demonstration. Our architecture comprises a Vue 3 TypeScript single-page application hosted on Vercel, an ASP.NET Core .NET 10 Web API backend on Railway, a specialized Python FastAPI AI service, and a PostgreSQL database managed by Supabase. Today, we'll demonstrate the complete workflow for our demo client, Nordic Tech AB."*

---

### Scene 2 – Admin Login (0:30–1:00)

Open `http://localhost:5173/login`. Enter `admin@nordic-recruit.demo` and demo password (`DEMO_USER_PASSWORD`). Click **Sign in**.

**Narration:**
> *"We begin by signing in as Seed Admin using Supabase Auth. The frontend securely acquires an ES256-signed JWT, which ASP.NET Core validates via JWKS. The client immediately calls `/api/account/me`, confirming our administrative role and rendering the Admin badge."*

---

### Scene 3 – Admin Customer Management & Act As (1:00–1:45)

Navigate to **Admin** view (`/admin`). Point to customer `recruiter@nordic-tech.demo` (Elin Recruiter / Nordic Tech AB).

**Narration:**
> *"In the Admin panel, the administrator can manage tenants. The .NET backend uses the server-side Supabase Service Role Key to manage identities without exposing credentials to the client. Admin can also use the 'Act As' feature to securely impersonate Elin Recruiter at Nordic Tech AB, scoping subsequent requests to their customerId."*

---

### Scene 4 – Customer Jobs Overview (1:45–2:30)

With customer context active, navigate to **Dashboard** (`/dashboard`). Show the two jobs:
1. **Senior Frontend Engineer** (Vue 3 + TypeScript)
2. **Backend Engineer .NET** (.NET 10 + Supabase + Python AI)

**Narration:**
> *"Now acting as Nordic Tech AB, our queries are strictly tenant-isolated. We see the two open positions: Senior Frontend Engineer and Backend Engineer .NET. The customer can manage openings and track candidate pipelines per requisition."*

---

Navigate to **Kanban** (`/kanban`). Show all 10 candidates populated across the board:
- **New (3):** Anna Lund, Elsa Moreau, Hugo Silva
- **Screening (2):** Erik Berg, Lucas Meyer
- **Interview (2):** Maria Karlsson, Nina Patel
- **Offer (1):** Jonas Nyström

**Narration:**
> *"The Kanban board gives recruiters immediate pipeline visibility. Our demo dataset seeds exactly 10 realistic candidates distributed across all six workflow stages. Each card presents candidate names, verified or missing LinkedIn profiles, and summary metadata."*

---

### Scene 6 – Kanban Filtering & Stage Progression (3:15–4:00)

Demonstrate interactive board features:
1. In the **Job filter** dropdown, select **Backend Engineer .NET**. Notice only Oscar Dahl, Nina Patel, and Hugo Silva appear.
2. In the **Search filter**, type `Nina`. Nina Patel is isolated immediately.
3. Clear search and change job filter to **All Jobs**. Search `Anna` to show Anna Lund.
4. Clear filters. Move **Hugo Silva** from **New** to **Screening** using the stage selector or drag action.

**Narration:**
> *"Filtering operates dynamically across the pipeline. We can filter by job title to isolate backend applicants, or search by name — typing 'Nina' or 'Anna' filters the board in real time. Moving Hugo Silva from New to Screening triggers an idempotent PATCH request to our .NET API, immediately persisting the candidate's new stage."*

---

### Scene 7 – AI CV Assessment Demonstration (4:00–4:40)

1. Locate **Anna Lund** in the **New** column. Click her card or the **Assess CV** action.
2. Observe that her AI score was initially null. The UI triggers `POST /api/candidates/{id}/assess`.
3. Show the newly populated score (e.g., 85+), strengths, concerns, and interview questions.
4. Contrast this by opening **Lucas Meyer** in **Screening**:
   - Lucas has a pre-calculated score of **42**.
   - Concerns clearly flag: *"No LinkedIn URL provided"*, *"CV text is short"*, and *"Limited evidence of Vue or TypeScript production use"*.

**Narration:**
> *"Next, we demonstrate the AI CV assessment. Anna Lund starts with null AI assessment fields. Clicking 'Assess CV' calls our .NET API, which dispatches candidate credentials to the Python FastAPI microservice. The service analyzes keyword relevance against the job requisition, generating an objective score, strengths, potential concerns, and suggested interview questions. In contrast, candidate Lucas Meyer scored 42, correctly highlighting his missing LinkedIn profile and concise CV."*
