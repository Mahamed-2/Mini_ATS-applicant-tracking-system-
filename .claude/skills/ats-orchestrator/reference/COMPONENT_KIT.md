# Prompt 1 – Component Kit Specification

Reusable UI components built with Vue 3, TypeScript, Tailwind tokens, and Lucide:
- Button (primary cobalt, secondary white/slate, danger rose, ai violet tint #f5f3ff/border #ddd6fe/text #7c3aed)
- Input, Textarea, Select, Checkbox (14x14, 3px radius), Switch, Label, Field (label+hint+error)
- Badge, Pill, Avatar (initials fallback), Card (Surface1), Panel (Surface2)
- StatCard (tabular-nums metric + label-sm caption + optional trend)
- Tabs, Table (zebra-free, 1px slate borders, sticky header), Dialog, Sheet/Drawer, Tooltip, Popover, DropdownMenu
- Skeleton, Spinner, EmptyState, ErrorState
- SearchInput (32px, leading Search icon, ⌘K chip slot)
- FilterBar, SegmentedControl, ScoreBadge (violet AI match %), StageChip (6 semantic tokens), ProviderChip
- Toast portal + useToast composable, ConfirmDialog
- ATS components: CandidateMicroCard, AiScoreRing, AiGlowPanel, MultiTenantSwitcher, LayerBreakdownCard, RouteSimulatorGrid, ConformanceNotesGrid
