# Prompt 5 – Page Re-Skinning Specification

Complete re-skin of all application views:
- `/jobs`: Table list with candidate count, status chip, sticky header, and `JobFormDialog`.
- `/candidates`: Table with avatar initials, LinkedIn icon/dash, StageChip, ScoreBadge, and `CandidateFormDialog`.
- `/kanban`: 6 columns with exact stage colors, drag lift shadow & 2deg rotate, name/job filters, and optimistic updates.
- `/candidates/:id`: Master-detail layout (60/40) with sticky scorecard header and `AiAssessmentPanel`.
- `/admin`: AdminSummaryCards, AdminUserTable, `CreateUserDialog`, and `ActAsCustomerSelector`.
