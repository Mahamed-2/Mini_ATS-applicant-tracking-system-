# Prompt 0 – Design Migration & Canonical Token Decisions

## Objective
Replace legacy frontend tokens and styles with the Recruiter Velocity ATS design system.

## Canonical Tokens
- AI/secondary violet = `#7c3aed` (strictly AI features only)
- Success emerald = `#059669`
- Primary cobalt = `#1d68f0`
- Canvas = `#f8f9ff` ; Card surface = `#ffffff` ; Borders = `#e2e8f0` / `#cbd5e1`
- Body text = `#0f172a` ; Muted = `#64748b` ; Variant = `#475569`
- Radius: Inputs/badges = 4px ; Cards/modals = 8px ; Stage chips/pills = 9999px
- Icons: Lucide only.
- Typography: Inter with tabular numbers (`tabular-nums`) on all counts, scores, and dates.
